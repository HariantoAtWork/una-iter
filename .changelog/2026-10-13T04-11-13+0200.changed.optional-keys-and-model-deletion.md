# API keys optional and provider model deletion

API keys are now optional when adding a provider, so local OpenAI-compatible
servers (Ollama, LM Studio, and similar) that need no key can be registered,
fetched and tested. The Authorization header is omitted when no key is
configured. The models drawer gains delete actions backed by new endpoints for
removing a single model row or clearing the whole catalogue, model tests now
cover all models instead of only enabled ones, and the keys/models drawers can
be deep-linked via `?keys=` / `?models=` query parameters on the providers page.
