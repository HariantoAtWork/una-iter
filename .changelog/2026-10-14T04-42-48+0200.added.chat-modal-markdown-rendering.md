Render assistant replies in the provider Chat modal as Markdown (via `marked`) and stream them as plain text, only switching to Markdown once a reply finishes. Parsing partial Markdown turned lone markers into broken or empty HTML, causing blank balloons and tables snapping in mid-stream.

Adds a `v-sanitize-html` directive (powered by DOMPurify) to render the markup safely, auto-registered by scanning `app/directives/` in a new Nuxt plugin since Nuxt does not import directives on its own.

Styles Markdown tables with a horizontally scrollable wrapper so wide tables no longer overflow the bubble, a bordered rounded frame, a shaded header, and full cell lines using `--ui-border-accented`/`--ui-bg-accented` so they stay visible against the elevated bubble in dark mode.
