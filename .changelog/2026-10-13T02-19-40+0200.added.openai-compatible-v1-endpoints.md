# OpenAI-compatible v1 endpoints and model routing

Added OpenAI-compatible `GET /v1/models` and `POST /v1/chat/completions`, exposed
as public middleware-excluded routes. Model ids are namespaced as
`{providerSlug}/{modelId}`, chat completions route to the matching provider using
Roundabout key order and rotate exhausted keys on 429/402, and only enabled
catalogue models are listed publicly.

Also fixed the admin model-test endpoint returning 500 on an empty POST body, and
added a copy-to-clipboard control per model row in the models drawer (with
click-through toasts) so the routable id is easy to grab.
