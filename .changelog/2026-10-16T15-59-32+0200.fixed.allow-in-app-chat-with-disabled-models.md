# Allow in-app chat with disabled models

The chat modal lists every model of a provider, but sending a message went
through the public OpenAI-compatible `/v1/chat/completions` route, which
rejects disabled models with a 404. That made it impossible to try a disabled
model from the app.

Add a session-authenticated `/api/chat/completions` route that reuses the
chat proxy with disabled models allowed, and point the chat modal at it.
External callers of `/v1/chat/completions` keep the strict enabled-only
behaviour.
