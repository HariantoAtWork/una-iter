# Add OpenCode preset and agent CLIs to docker image

Add OpenCode (`https://opencode.ai/inference/v1`) to the searchable provider
preset pulldown in Add / Edit Provider, under "Free tier", so it can be picked
without typing a base URL. Also install the Pi coding agent CLI
(`@earendil-works/pi-coding-agent`) and the OpenCode CLI (`opencode-ai`) in the
runner stage of both Dockerfile and Dockerfile.platform via `bun add -g`; bun
places the global bins in /usr/local/bin and both run directly on the image
runtime.
